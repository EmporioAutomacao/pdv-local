# Sync Security Baseline

## Goal
Apply minimum security baseline for synchronization channels.

## Mandatory Controls
1. TLS in transit
2. mTLS per installation
3. Short-lived access tokens
4. Least-privilege credentials on source system
5. Secret storage in OS-protected vault
6. Structured audit logs without sensitive leakage

## Verification
- Threats mapped
- Controls implemented
- Failure modes tested
- Audit trail queryable
